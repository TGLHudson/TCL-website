# TCL website

Website for *The Culture Ladder* by T. G. L. Hudson (CRC Press, February 2027).

Work on this site happens in Claude Code cloud sessions. The working brief, with rules and open decisions, is in [CLAUDE.md](CLAUDE.md).

## Structure

Plain HTML pages at the root (`index.html`, `book.html`, `consulting.html`, `author.html`, `contact.html`, `404.html`), styles and icon in `assets/`. No build step: GitHub Pages serves the files as they are. To preview, open `index.html` in a browser.

The proposal behind this build, the research and the decisions still open are in [docs/PROPOSAL.md](docs/PROPOSAL.md).
