# TCL website

Website for *The Culture Ladder* by T. G. L. Hudson (CRC Press, February 2027).

Work on this site happens in Claude Code cloud sessions. The working brief, with rules and open decisions, is in [CLAUDE.md](CLAUDE.md). Colours, type and components follow [STYLE.md](STYLE.md), the style guide shared with [hudsonglobalconsulting.com](https://hudsonglobalconsulting.com) and [hudsonriskculture.com](https://hudsonriskculture.com).
